# PentAGI 2.1.0: комплект для Proxmox LXC

Скачайте все пять файлов `pentagi-proxmox-images-v2.1.0-amd64.tar.zst.part-00` ... `part-04` в корень клонированного репозитория. Затем выполните:

```bash
sha256sum -c parts.sha256
./assemble-images.sh
```

Получившийся `images.tar.zst` содержит шесть Docker-образов для amd64. Его SHA-256: `e8239e228d7ac769f0fd0d4e0dd558ad71c9081fac9a19b27bdd5408a71b994c`. Архив проверен загрузкой в Docker; PentAGI 2.1.0 и три вспомогательных сервиса запускались локально, API ответил HTTP 200, в Kali подтверждены десять основных инструментов.

Для установки на Proxmox заполните `config.env` по примеру и следуйте [README_RU.md](README_RU.md). Установка на конкретном узле Proxmox и работа LLM-провайдера требуют параметров узла и ключа провайдера; они не включены в релиз.
